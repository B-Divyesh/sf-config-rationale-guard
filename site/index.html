03 How it works

Add a rationale next to each decision.

The source config remains unchanged. The CLI writes and checks a separate JSON rationale file beside it.

  1. 1

    Create the sidecar

    Generate one adjacent decision record for each config leaf.

    crg init agent.json
  2. 2

    Write and stamp

    Add the reason, then fingerprint the reviewed setting.

    crg stamp agent.json
  3. 3

    Check before CI

    Find missing, orphaned, overdue, schema-invalid, or stale decision records.

    crg check agent.json --schema schema.json

04 Data handling

Keep values out of review reports.

Reports show paths, rationale, and status. They do not print configuration values. The demo sends no input away from this site.

It does not rewrite source configuration or require a cloud service.

05 Install

Build the CLI and run a check.

Use Rust 1.85 or later. The sample command works without prompts, and --json produces a scriptable report.

INSTALL / SOURCE● ●
