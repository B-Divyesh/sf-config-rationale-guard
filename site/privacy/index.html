How this tool handles your data.

The CLI runs locally. The browser demo keeps its sample input in a separate local demo space.

Configuration and reports

Reports show paths, rationale, and status without configuration values. The CLI does not rewrite the source configuration file.

Browser demo

The demo processes the shipped sample in your browser. Any temporary input uses a local-storage key beginning with demo:config-rationale-guard:. Resetting the demo or choosing Start for real removes that demo input.

Site requests

This site makes no requests to analytics, advertising, tracking, or third-party scripts during the demo flow. It serves its own font, image, and script files.

Contact

Privacy questions can be sent to privacy@sociobot.in.
